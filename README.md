# Index Fund Drawdown

A single-page planner for investing in and then withdrawing from an
index fund portfolio. Set the starting balance, a monthly investment,
the year withdrawals start, the withdrawal rate, annual return,
inflation and time horizon; the page shows the first withdrawal and a
year-by-year chart of investments, withdrawals and the balance.

Live: https://prmichaelsen.github.io/drawdown-planner/

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-prmichaelsen-1f5fb8?logo=buymeacoffee&logoColor=white)](https://buymeacoffee.com/prmichaelsen)

Two withdrawal modes:

- **First-year amount, raised with inflation** (the "4% rule" style).
- **Same % of each year's balance.**

Assumes a constant return, monthly investments compounding monthly,
withdrawals at the start of each year, and no taxes or fees. An
estimate, not financial advice.

No build step: `index.html` is the whole app.
